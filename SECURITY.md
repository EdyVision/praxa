# Security Policy

## Supported versions

Security fixes are accepted against the latest published release on `main` (currently the `0.2.x` line).

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Prefer one of:

1. [GitHub Security Advisories](https://github.com/EdyVision/praxa/security/advisories/new) for this repository
2. Email the maintainer via the contact listed on [github.com/EdyVision](https://github.com/EdyVision)

Include a clear description, impact, and reproduction steps when possible. You should receive an acknowledgment within a few business days.

## Scope notes

Praxa is a research library. It does not ship hosted services. Reports about third-party models, datasets, or consumer training harnesses should go to those projects.
